# 第 03 章 機率、高斯分布與貝氏定理：段落觀念整理

本文整理 `03-Gaussians.ipynb` 各段落要傳達的觀念。這一章的核心任務是回答一個問題：**為什麼要用高斯分布取代上一章的離散陣列？** 前半是統計基礎，後半說明高斯在計算上的優點，並說明它的限制。

---

## 1. 簡介：動機
- 離散貝氏濾波器是多峰的，而且要儲存、計算整個陣列，成本很高。
- 追蹤問題要的是**單峰、連續、計算有效率**的表示法，高斯分布三項都符合。
- **觀念**：這一段先把整章的目標講清楚。

---

## 2. 統計基礎：平均值、變異數與標準差

### 2.1 隨機變數與樣本空間
- 擲骰子的結果是決定性的，但我們缺乏資訊，所以用機率描述。「隨機」指的是**資訊不足**，不是過程不確定。
- 樣本空間是所有可能結果的集合，例如骰子是 {1,…,6}，硬幣是 {H, T}。
- 離散隨機變數（骰子、硬幣）與連續隨機變數（身高）的差別在於樣本空間是可數還是不可數。
- 量測的精度與真實值不同：量測只能到 0.1 公尺，但真實身高仍是連續的。
- **觀念**：隨機變數是「數值 + 對應機率」的組合，而量測值不等於真實值。

### 2.2 機率分布
- 機率分布給出隨機變數取每個值的機率。骰子的分布是每個面 1/6。
- 記號：小寫 $p(x)$ 是分布函數，大寫 $P(X=x)$ 是單一事件的機率。書中提醒兩者容易混淆。
- **觀念**：機率分布的所有機率非負，且總和為一。

### 2.3 平均值、中位數與眾數
- 平均值（mean）是所有值加總除以個數，記為 $\mu$。
- 眾數（mode）是出現次數最多的值。若只有一個峰，稱為**單峰（unimodal）**；有多個峰，稱為**多峰（multimodal）**。
- 作者之後會用「單峰／多峰」描述信念，離散貝氏章節的狗位置信念就是多峰的。
- **觀念**：集中趨勢有多種量法，它們各自描述資料的不同面向。

### 2.4 期望值
- 期望值是無限多次取樣後的平均，等於各值乘以機率再加總。
- 例子：$x = [1,3,5]$，機率分別為 0.8、0.15、0.05，期望值為 $1.5$。
- 連續情況用積分計算，書中用均勻分布做練習。
- **觀念**：期望值是以機率加權的平均。

### 2.5 變異數與標準差
- 平均值無法描述資料的分散程度。三個班級的身高平均都是 1.8 公尺，但分散程度不同。
- 變異數 $\mathit{VAR}(X) = \mathbb E[(X-\mu)^2]$，標準差 $\sigma = \sqrt{\mathit{VAR}(X)}$。
- 標準差的單位與原資料相同，比變異數更容易解讀。
- 書中常用 $\sigma^2$ 表示變異數。
- **觀念**：變異數衡量分散程度，標準差是它的平方根。

### 2.6 為什麼取平方
- 不平方會因正負抵銷而得到零。
- 取絕對值時，$[3,-3,3,-3]$ 與 $[6,-2,-3,1]$ 會得到相同的結果，無法區分分散程度不同的資料。
- 取平方後可以區分，但對離群值過度敏感，因為離群值的平方會被放大。
- 作者說明這是 Gauss 的定義，有其武斷之處，並提到 robust statistics 作為另一種方向。
- **觀念**：摘要統計量永遠不完整，它只能精簡地描述資料，不能取代完整資料。

## 3. 高斯分布

### 3.1 機率密度函數（pdf）
- 連續分布中，某個精確值的機率為零，有意義的是曲線下的**面積**。
- pdf 顯示隨機變數取某值的相對可能性，曲線下總面積為一。
- **觀念**：連續分布用密度描述，機率來自面積。

### 3.2 術語：模型不等於現實
- 「地圖不是疆域」：高斯是模型，它的尾部延伸到無窮遠，這對身高或車速明顯不合理。
- 高斯被廣泛使用，主要是因為它**比其他相對準確的選擇更容易計算**。
- **觀念**：模型的選擇是實用與準確之間的取捨。

### 3.3 高斯分布的兩個參數
- 高斯分布完全由平均值 $\mu$ 與變異數 $\sigma^2$ 決定，記為 $\mathcal N(\mu,\sigma^2)$。
- 只用兩個數字，就能描述無限多個可能值的分布。這是高斯最重要的特性。
- 溫度計的例子：讀數 22°C，$\mathcal N(22, 4)$ 表示量測值的分布，$\sigma=2$。
- 注意：有些書用 $\mathcal N(\mu,\sigma)$，本書用 $\mathcal N(\mu,\sigma^2)$。
- **觀念**：兩個參數就能完整描述一個量測的不確定性。

### 3.4 變異數與信念
- 曲線下面積必須為 1，所以變異數小時曲線又窄又高，變異數大時又寬又矮。
- $\sigma^2 = 0.2^2$ 表示非常確定，$\sigma^2 = 1^2$ 表示不太確定。
- 把它想成溫度計：小變異數是準確的溫度計，大變異數是不準的溫度計。
- **觀念**：變異數就是不確定性的大小。

### 3.5 68-95-99.7 法則
- 高斯分布約 68% 落在 $\pm1\sigma$，95% 在 $\pm2\sigma$，99.7% 在 $\pm3\sigma$。
- 例子：平均 71、標準差 9.4 的考試成績，95% 介於約 52 到 90 之間。
- **觀念**：標準差讓「多大的差異算大」有了具體的意義。

### 3.6 互動式高斯與動畫
- 書中提供滑桿，讓讀者調整 $\mu$ 與 $\sigma^2$，觀察曲線移動與變胖變瘦。
- **觀念**：$\mu$ 決定位置，$\sigma^2$ 決定寬度。

## 4. 高斯的計算性質（承上啟下的關鍵）

### 4.1 兩個高斯相加
- 兩個獨立高斯相加仍是高斯：$\mu = \mu_1+\mu_2$，$\sigma^2 = \sigma_1^2+\sigma_2^2$。
- 對應濾波器的 **predict**：移動量加到位置上。

### 4.2 兩個高斯相乘
- 相乘的結果不是高斯，但與一個高斯成正比，因此可以視為高斯函數。
- 公式：$\mu = \dfrac{\sigma_1^2\mu_2+\sigma_2^2\mu_1}{\sigma_1^2+\sigma_2^2}$，$\sigma^2 = \dfrac{\sigma_1^2\sigma_2^2}{\sigma_1^2+\sigma_2^2}$。
- 對應濾波器的 **update**：prior 乘以 likelihood。
- **觀念**：在非線性函數中，相乘通常會改變形狀，但高斯是特例。這就是 Kalman filter 能計算的原因。

### 4.3 計算量的比較
- 離散 update 要對每個格子做乘法，百萬格就要百萬次乘法。
- 高斯版只需要三次乘法和兩次除法，用 $(\mu,\sigma^2)$ 取代整個陣列。
- **觀念**：從 O(N) 降到 O(1)，這是 Kalman filter 的核心優勢。

## 5. 整合：貝氏定理與全機率定理

### 5.1 貝氏定理
- 上一章的 `update()` 實際上就是貝氏定理：$\text{posterior} = \dfrac{\text{likelihood}\times\text{prior}}{\text{normalization}}$。
- 可以讀成「新知識 = 正規化（新資訊的似然 × 舊知識）」。
- 作者的觀點：數學有時會掩蓋這個簡單的想法。
- **觀念**：貝氏定理是更新信念的規則。

### 5.2 全機率定理
- `predict()` 對應全機率定理：$P(X_i^t) = \sum_j P(X_j^{t-1})P(x_i\mid x_j)$。
- 意思是：各種可能的前一狀態，經由移動機率加總，得到目前的狀態機率。
- **觀念**：預測是把所有可能來源加總。

## 7. 用高斯為世界建模的限制

### 7.1 中央極限定理與它的條件
- 中央極限定理說：大量獨立隨機變數的和趨近常態分布，但這需要「在某些條件下」。
- 物理世界常不滿足這些條件。例如廚房秤不會讀到負值，但高斯的左尾延伸到負無窮。

### 7.2 考試成績的例子
- 考試成績不可能是常態分布，因為高斯對任何值都給非零機率。例如平均 90、標準差 13 的考試，高斯仍會給 150 分或 -10 分極小的機率。
- 實際上高分端的分布會較「胖」，因為分數有上限。

### 7.3 感測器誤差不是真正的高斯
- Kalman filter 的數學建立在理想化的模型上。
- 作者引入 Student's t 分布，用來產生有離群值的模擬資料，後面章節用它測試濾波器。
- NASA 的例子：理論上用 3σ 區分雜訊與有效量測，實務上需要 5–6σ。
- **觀念**：高斯假設不成立時，Kalman filter 就不是最佳的，設計者需要知道這一點。

### 7.4 小樣本的統計量不可靠
- 小樣本的偏態（skew）與峰度（kurtosis）偏離零，因為樣本數不足以平均分布。
- 大樣本的平均與變異數才接近理論值。
- **觀念**：統計量的可信度取決於樣本數。

## 8. 選讀：乘積與和的推導
- 乘積用貝氏定理推導：prior 與量測的似然相乘，配方後得到均值與變異數的公式。
- 和用卷積（convolution）推導。
- 書中說明不讀推導也沒關係，記住結果即可。
- **觀念**：推導是為了讓公式可信，對實作不是必要。

---

## 9. 小結：必須理解的重點
- 常態分布表示連續的機率分布。
- 完全由平均值 $\mu$ 與變異數 $\sigma^2$ 描述。
- $\mu$ 是所有可能值的平均，$\sigma^2$ 是量測偏離平均的程度。
- 標準差 $\sigma$ 是變異數的平方根。
- 自然界很多量近似常態，但數學上並不完美。
- 濾波中計算 $p(x\mid z)$ 很困難，但計算 $p(z\mid x)$ 很直接，貝氏定理能連接兩者。
- **觀念**：這些重點是後面 Kalman filter 的基礎。
